# HOST RUN Level 2 Content Pass

Status: queued after the current UX/content stabilization pass.

## Why this pass exists

The learner has not read the source packets. The app must teach the material before it tests recall. No acronym, wine term, historical reference, production method, place name, or cultural reference should appear as if the learner already knows it.

## Research and pedagogy standard

- Define unfamiliar language at first use, in the sentence or immediately beside it.
- Keep the connected narrative first; put supporting receipts and drills after the story.
- For every important fact, explain what it means and why it matters to the tour or host performance.
- Use primary or authoritative sources for factual expansion whenever possible.
- Record source title, organization, URL, and access date for researched additions.
- Clearly distinguish packet-sourced claims from independently researched context.
- Do not add trivia that does not improve understanding, memory, or host readiness.
- Rewrite fragmented fact piles into cause-and-effect stories with clear transitions.
- Check that audio narration and captions contain the same definitions as the visible lesson.
- Test every episode with the question: “Could Lauren understand and retell this without ever reading the packet?”
